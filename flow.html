3. AI OCR — มี และอ่านเฉพาะสลิปโอนเงิน

ใช้ OpenAI (โมเดลเริ่มต้น gpt-5-mini) คีย์อยู่ใน Script Properties ของ Apps Script หน้าเว็บไม่เห็นคีย์

อ่านอะไร
สลิปธนาคาร พร้อมเพย์ e-Wallet หน้ายืนยันชำระบัตร รายการเดินบัญชีที่แคปหน้าจอ
ได้อะไร
ประเภทเอกสาร · ชื่อผู้โอน · ชื่อผู้รับเงิน · ยอดที่โอน · วันที่และเวลา · Transaction ID · บันทึกช่วยจำ · ธนาคารต้นทาง/ปลายทาง · ค่าธรรมเนียม · ความมั่นใจ
เติมช่องไหน
ตาราง "ข้อมูลที่ AI อ่านจากสลิป" ในการ์ด AI VISION (แก้ได้ทุกช่อง → บันทึกลงคอลัมน์ W–AE และทะเบียนโอนเงินออก) · จำนวนเงิน (ถ้ายังว่าง) · วันที่จ่าย · ร้าน/ผู้รับเงิน · หมายเหตุ "สลิป: อ้างอิง … จาก KBank · เวลา 10:50" — ช่องที่เติมขึ้นสีทอง ต้องตรวจ · ไม่มี AI ก็กด "กรอกข้อมูลสลิปเอง" ได้
ยอดต่างประเทศ
รูปในช่องยอดบาทที่กลายเป็น Alipay ¥4,738 → ไม่เติมยอด แต่เตือนให้ย้ายไปช่องสกุลต่างประเทศ และแนบรายการเดินบัญชีที่เห็น ฿23,908.72 ในช่องยอดบาท · รูปในช่องสกุลต่างประเทศไม่ถูกส่งให้ AI
ไม่ทำอะไร
ไม่อ่านใบเสร็จ ไม่เลือกหมวด ไม่บันทึกเอง — ทุกรายการยังไปที่สถานะ "รอตรวจ"
ทำงานตอนไหน
ทันทีที่แนบหลักฐานการชำระเงิน (ปิดอัตโนมัติได้ในหน้าตั้งค่า) ถ้ารูปแรกไม่ใช่สลิปลองรูปถัดไปให้เอง สูงสุด 3 รูป
ปิด/เปิด
ชีตตั้งค่า AI_OCR = off · ไม่มี OPENAI_API_KEY = แอปบอกว่า AI ยังไม่พร้อม แล้วให้กรอกเอง

5. ฐานข้อมูล CSV บน GitHub

ไฟล์คอลัมน์ใช้ทำอะไร
staff.csvชื่อเล่น · ชื่อ-นามสกุล · แผนก · ไฟล์ลายเซ็น · บทบาท (staff / intern / approver)ปุ่มชื่อในขั้นที่ 1 · ชื่อและลายเซ็นบนใบปะหน้า · บทบาท approver = ผู้อนุมัติที่ใส่ให้อัตโนมัติ (ฝ้าย = อานนท์ หม้อสุวรรณ) · จู = Admin / เลขา / บัญชี
categories.csvหมวดหมู่ · โฟลเดอร์ใน Drive · ประเภทในใบปะหน้า · ตัวอย่างปุ่มหมวดในขั้นที่ 3 · โฟลเดอร์ปลายทาง · ช่อง ☑ ที่ติ๊กในใบปะหน้า
signatures/ไฟล์ PNG พื้นโปร่งลายเซ็นของแต่ละคน อ้างจากคอลัมน์ไฟล์ลายเซ็น

แก้ไฟล์บน GitHub (Edit → Commit) แอปโหลดใหม่ทุกครั้งที่เปิด ถ้าโหลดไม่ได้ใช้สำเนาล่าสุดที่จำไว้ในเครื่อง คนที่ไม่มีไฟล์ลายเซ็นจะได้ช่องวาดลายเซ็นในแอปแทน

6. สถานะและหน้าที่ของแต่ละคน

สถานะบัญชีหมายถึงใครเปลี่ยน
รอตรวจทุกรายการที่เพิ่งบันทึกระบบ
ตรวจแล้วบัญชีดู PDF และหมวดครบแล้ว รอลง FlowAccountบัญชี
บันทึกบัญชีแล้วลงบัญชีเรียบร้อยบัญชี
ตีกลับขาดหลักฐานหรือข้อมูลผิด เขียนเหตุผลในคอลัมน์ S พนักงานเห็นในแอปแล้วบันทึกรายการใหม่ให้ถูกต้องบัญชี
พนักงาน
บันทึกทันทีที่จ่าย แนบสลิปที่เห็นยอดบาท ตรวจช่องสีทองที่ AI เติม ดูตัวอย่างเอกสารก่อนยืนยัน
ผู้อนุมัติ
ฝ้าย (อานนท์ หม้อสุวรรณ) — ลายเซ็นใส่ให้อัตโนมัติบนใบปะหน้า ตรวจภาพรวมจาก Dashboard
ฝ่ายบัญชี
ตรวจแถวรอตรวจ เปิด PDF ลง FlowAccount เปลี่ยนสถานะ จ่ายคืนพนักงานตามคอลัมน์สถานะเบิกคืน
ผู้ดูแลระบบ

ผลลัพธ์ของทุกรายการคือ **ไฟล์ PDF หนึ่งไฟล์** (ใบปะหน้าถ้าไม่มีใบเสร็จ + ใบเสร็จ + สลิป) เก็บในโฟลเดอร์ ปี/เดือน/หมวดหมู่ ใน Drive และ 1 แถวใน **ชีตของเดือนนั้น** (เดือนละชีต ชื่อ `2026-09`)

```
เข้าสู่ระบบด้วย Google (3 บัญชีของบริษัท)  →  1 ใครบันทึก  →  2 มีใบเสร็จไหม  →  3 หมวดหมู่  →  4 รายละเอียด  →  5 ตรวจสอบ PDF แล้วกดยืนยัน
```

## 1. ขั้นตอนใช้งาน (พนักงาน)

0. **เข้าสู่ระบบด้วย Google** — หน้าแรกคือปุ่ม Sign in with Google ใช้ได้เฉพาะ `ceo.anoney.potter@gmail.com`, `anoney.potter@gmail.com`, `tesrshop@gmail.com` (บัญชีอื่นขึ้น "ไม่ได้รับอนุญาต") · ล็อกอินครั้งเดียวจำไว้ในเครื่อง ต่ออายุอัตโนมัติ · ออกจากระบบได้ในหน้าตั้งค่า
1. **ใครบันทึก** — แตะชื่อตัวเอง (ฝ้าย ซัน โอ๊ต จู พีค ฟาม) · "เด็กฝึกงาน" หรือ "คนอื่นๆ" พิมพ์ชื่อ-นามสกุลและแผนก แล้ว**วาดลายเซ็นด้วยนิ้ว**หรืออัปโหลดรูปลายเซ็นได้ (จำไว้ในเครื่อง) — คนที่มีไฟล์ลายเซ็นใน GitHub ระบบใส่ให้อัตโนมัติ
2. **มีใบเสร็จไหม** — เลือก "มีใบเสร็จ" หรือ "ไม่มีใบเสร็จ"
3. **หมวดหมู่** — แตะหมวด (17 หมวดจาก categories.csv) = โฟลเดอร์ปลายทางใน Drive
4. **รายละเอียด**
   - *มีใบเสร็จ*: ถ่ายใบเสร็จ (หรือเลือกไฟล์อัปโหลด) → แนบ**สลิป/หลักฐานการจ่ายที่เห็นยอดเป็นบาท** (จำเป็น) → ถ้าโอนเป็น USD/RMB แนบ**หน้าตอนโอนสกุลต่างประเทศ** (Alipay/PayPal/บัตร) เพิ่มในช่องถัดไป เพื่อให้เห็นทั้งตอนโอนและตอนแปลงเป็นบาทแล้ว → AI อ่านสลิปเติมยอด วันที่ ผู้รับเงิน → เลือกจ่ายด้วยเงินบริษัทหรือเงินส่วนตัว
   - *ไม่มีใบเสร็จ*: กรอก**ใบปะหน้า** (เอกสารประกอบการเบิกค่าใช้จ่าย): วันที่ · ประเภท (ค่าพาหนะ / ค่าสินค้าและบริการ + สาเหตุที่ไม่มีใบเสร็จ / อื่นๆ) · รายการและจำนวนเงิน (หลายบรรทัดได้) · แนบสลิปยอดบาท (จำเป็น) · หลักฐานตอนโอนสกุลต่างประเทศ (ถ้ามี) · รูปสินค้าถ้ามี
   - ปุ่มแนบทุกช่องมี 2 แบบ: **ถ่าย** (กล้อง) และ **เลือกไฟล์อัปโหลด** (รูปหรือ PDF จากเครื่อง)
5. **ตรวจสอบ** — เห็นหน้าเอกสารทั้งหมดเหมือนที่จะถูกเก็บ (ใบปะหน้ามีลายเซ็นผู้ขอเบิกและผู้อนุมัติ **อานนท์ หม้อสุวรรณ** ใส่ให้อัตโนมัติ) · กด "สร้างไฟล์ PDF ตัวอย่าง" เพื่อเปิดดูไฟล์จริงได้ · กด **ยืนยันและบันทึก** → ระบบเก็บ PDF ลง Drive และบันทึกลงชีต แล้วแสดงเลขรายการ

แท็บ **รายการ** ดูรายการของตัวเอง สถานะที่บัญชีตรวจ ลิงก์ PDF และยอดรอจ่ายคืน

## 2. ติดตั้ง (ผู้ดูแล — 15 นาที)

### 2.1 Google Sheet + Apps Script
1. สร้าง Google Sheet ใหม่ → **ส่วนขยาย → Apps Script** → วาง `Code.gs` ทับ → บันทึก
2. เลือกฟังก์ชัน **`setup`** → Run → อนุญาตสิทธิ์ (สร้างชีต `Dashboard` `ตั้งค่า` ชีตแม่แบบ (ซ่อน) ชีตของเดือนปัจจุบัน และโฟลเดอร์ Drive "TESR Ledger — หลักฐานรายจ่าย" · ถ้ามีชีต `รายจ่าย` แบบเดิมอยู่ จะย้ายแถวไปชีตรายเดือนให้อัตโนมัติ)
3. **Deploy → New deployment → Web app** · Execute as: **Me** · Access: **Anyone** → คัดลอก URL `/exec`
   > แก้โค้ดภายหลังต้อง Deploy → Manage deployments → New version
4. **Script Properties** (⚙ Project settings): `OPENAI_API_KEY` (ให้ AI อ่านสลิป) และ `APP_TOKEN` (รหัสร่วมของทีม แนะนำตั้ง)

### 2.2 GitHub Pages — repo นี้: `TESR-Channel/TESR-LEDGER`
1. ไฟล์ทั้งหมดอยู่ใน repo แล้ว (`index.html`, `config.js`, `styles.css`, `app-*.js`, `logo.js`, `Code.gs`, `staff.csv`, `categories.csv`, `signatures.json`, `flow.html`, `README.md`) · ไฟล์รูป `logo.png`, `logo-192.png`, `signatures/*.png` อยู่ใน zip — อัปโหลดเพิ่มได้ผ่าน **Add file → Upload files** (ใช้เป็นไอคอน Add to Home Screen; แอปมีโลโก้และลายเซ็นฝังไว้แล้ว จึงไม่บังคับ)
2. เปิด `config.js` แก้ `API_URL` เป็น URL จากข้อ 2.1 (และ `APP_TOKEN`) — ทีมจะไม่ต้องตั้งค่าอะไรเลย (หรือให้ตั้งเองที่ ⚙ ในแอป)
3. **Settings → Pages → Build and deployment: Deploy from a branch → main / (root)** → ได้ลิงก์ `https://tesr-channel.github.io/TESR-LEDGER/` ส่งให้ทีม → Add to Home Screen

### 2.3 เปิดใช้ล็อกอิน Google (5 นาที)
1. เปิด [console.cloud.google.com](https://console.cloud.google.com) → สร้างโปรเจกต์ (หรือใช้โปรเจกต์เดิม) → **APIs & Services → OAuth consent screen** → External → ใส่ชื่อแอป "TESR Ledger" และอีเมลติดต่อ → บันทึก (scope ใช้แค่ email/profile ไม่ต้องขอ verify) → ในหน้า Audience/Test users เพิ่ม 3 อีเมลของบริษัท หรือกด Publish app
2. **Credentials → Create credentials → OAuth client ID → Web application** · Authorized JavaScript origins ใส่ `https://tesr-channel.github.io` (ไม่มี path) · Create → คัดลอก **Client ID** (ลงท้าย `.apps.googleusercontent.com`)
3. วาง Client ID ใน `config.js` → `GOOGLE_CLIENT_ID` **และ** ในชีต **ตั้งค่า** → `GOOGLE_CLIENT_ID` (หลังบ้านตรวจ token กับ Google ทุกคำขอ) · รายชื่ออีเมลที่อนุญาตอยู่ที่ `ALLOWED_EMAILS` ใน config.js และชีตตั้งค่า `ALLOWED_EMAILS` (ชีตเป็นตัวตัดสิน)
4. ทดสอบเปิดหน้าเว็บ → ปุ่ม Sign in with Google → เลือกบัญชีบริษัท → เข้าสู่ขั้นตอนที่ 1 · ทุกแถวในชีตจะบันทึกบัญชี Google ที่ล็อกอิน (คอลัมน์ V)

> ยังไม่ได้ใส่ Client ID: หน้าแรกจะแจ้ง "ผู้ดูแลยังไม่ได้ใส่ GOOGLE_CLIENT_ID" และใช้ต่อไม่ได้ (ตั้ง `LOGIN_REQUIRED: false` ใน config.js ชั่วคราวได้ถ้าจะทดสอบโดยไม่ล็อกอิน)

### 2.4 แก้รายชื่อ / หมวดหมู่ (บน GitHub)
- `staff.csv` — คอลัมน์: `ชื่อเล่น, ชื่อ-นามสกุล, แผนก, ไฟล์ลายเซ็น, บทบาท` · บทบาท `approver` = ผู้อนุมัติ (ชื่อและลายเซ็นบนใบปะหน้า — ตอนนี้คือ ฝ้าย/อานนท์ หม้อสุวรรณ) · `intern` / `other` = ต้องพิมพ์ชื่อเอง · ชื่อ-นามสกุลครบทุกคนแล้ว (ซัน/โอ๊ตอ่านจากลายเซ็น ตรวจอีกครั้งได้)
- `categories.csv` — คอลัมน์: `หมวดหมู่, โฟลเดอร์ใน Drive, ประเภทในใบปะหน้า (ค่าพาหนะ / ค่าสินค้าและบริการ / อื่นๆ), ตัวอย่าง` · ลำดับในไฟล์ = ลำดับปุ่มในแอป
- แอปโหลดไฟล์ทั้งสองใหม่ทุกครั้งที่เปิด (และมีปุ่ม "โหลดรายชื่อ/หมวดหมู่ใหม่" ในหน้าตั้งค่า)

**ใน PDF** — หน้า 1 ใบปะหน้า (เฉพาะไม่มีใบเสร็จ) → หน้าถัดไป ใบเสร็จ / หลักฐานการจ่าย (ยอดบาท) / หลักฐานตอนโอน (สกุลต่างประเทศ) / รูปสินค้า (หัวกระดาษระบุวันที่ ผู้บันทึก หมวด ยอด แต่ละรูปมีป้ายบอกว่าเป็นหลักฐานประเภทไหน) → ไฟล์ PDF ที่แนบ (ถ้ามี) ต่อท้าย

**Google Sheet — เดือนละชีต** ชื่อชีต = ปี-เดือน ตามวันที่จ่าย (`2026-09`, `2026-10` …) ระบบสร้างให้เองจากชีตแม่แบบเมื่อมีรายการแรกของเดือน และเรียงแท็บ Dashboard · ตั้งค่า · เดือนใหม่ → เก่า ฝ่ายบัญชีเปิดชีตของเดือนที่จะตรวจได้ทันที ไม่ปนกับเดือนอื่น
แต่ละชีตมี 22 คอลัมน์: ID · บันทึกเมื่อ · วันที่จ่าย · งวด · ผู้บันทึก · ชื่อ-นามสกุล · แผนก · ใบเสร็จ (มี/ไม่มี) · หมวดหมู่ · รายละเอียด · ร้าน/ผู้รับเงิน · จำนวนเงิน · จ่ายโดย · สถานะเบิกคืน · เอกสาร PDF (ลิงก์ชื่อไฟล์) · จำนวนหน้า · สถานะบัญชี · หมายเหตุผู้บันทึก · หมายเหตุบัญชี · ผู้อนุมัติ · ประเภท/เหตุผลในใบปะหน้า · บัญชี Google ที่ล็อกอิน — บัญชีแก้เฉพาะ **สถานะบัญชี** (รอตรวจ → ตรวจแล้ว → บันทึกบัญชีแล้ว / ตีกลับ), **สถานะเบิกคืน** และ **หมายเหตุบัญชี** · เลขรายการ `EXP-ปี-ลำดับ` นับต่อเนื่องทั้งปีข้ามชีต

**Dashboard** — ช่อง B2 เลือกเดือน (dropdown): รวม จำนวน ไม่มีใบเสร็จ รอตรวจ รอจ่ายคืน · ตามหมวดหมู่ · ตามผู้บันทึก · รายการรอจ่ายคืนของเดือนนั้น · ตาราง **ทุกเดือน** (คอลัมน์ L–Q) รวมยอด จำนวน รอตรวจ รอจ่ายคืน พร้อมลิงก์เปิดชีตแต่ละเดือน · แท็บ "รายการ" ในแอปแสดงรายการรอจ่ายคืนข้ามทุกเดือน

## 4. AI OCR (OpenAI) — อ่านเฉพาะสลิปโอนเงิน
- เมื่อแนบรูปในช่อง "สลิป/หลักฐานการจ่ายที่เห็นยอดเป็นบาท" ระบบส่งรูปให้ OpenAI (`gpt-5-mini`) อ่าน **ยอด วันที่ เวลา ผู้รับเงิน ธนาคาร เลขอ้างอิง** แล้วเติมช่องยอด/วันที่/ร้าน/หมายเหตุ (ขึ้นสีทอง ต้องตรวจ)
- ถ้ารูปแรกไม่ใช่สลิปจะลองรูปถัดไปให้เอง (สูงสุด 3 รูป) · ถ้ารูปในช่องนี้เป็นสกุลต่างประเทศ (เช่น Alipay ¥) ระบบไม่เติมยอดและเตือนให้ย้ายไปช่อง "หลักฐานตอนโอนสกุลต่างประเทศ" แล้วแนบหลักฐาน**ยอดบาท**แทน · รูปในช่องสกุลต่างประเทศไม่ถูกส่งให้ AI
- ไม่อ่านใบเสร็จ ไม่เลือกหมวดให้ ไม่บันทึกเอง · ปิดได้ที่ชีตตั้งค่า `AI_OCR = off` หรือปิดอัตโนมัติในหน้าตั้งค่าของแอป

## 6. หมายเหตุทางเทคนิค
- หน้าเว็บ responsive: ขนาดตัวอักษรรากคำนวณจากความกว้างจอ (16px บนมือถือ → 19px บนจอกว้าง) ความกว้างเนื้อหา 760 / 920 / 1,080 / 1,200 px ตามจอ · จอ ≥ 1,100px ขั้นที่ 4 จัดการ์ดเป็น 2 คอลัมน์ · หมวดหมู่ 2 คอลัมน์บนแท็บเล็ตขึ้นไป · ใบปะหน้าที่แปลงเป็น PDF ใช้ขนาดคงที่เสมอ ไม่ขึ้นกับจอ
- ชีตรายเดือนถูกคัดลอกจากชีต **แม่แบบ** (ซ่อนอยู่) — ถ้าอยากเปลี่ยนสี ความกว้าง หรือ dropdown ให้แก้ที่แม่แบบ (ยกเลิกซ่อนชั่วคราว) แล้วชีตเดือนถัดไปจะได้รูปแบบใหม่ · เมนู TESR Ledger → "สร้างชีตเดือนปัจจุบัน" สร้างชีตล่วงหน้าได้
- PDF ประกอบขึ้น**ในเบราว์เซอร์** (html2canvas + pdf-lib จาก cdnjs) จึงเห็นตัวอย่างก่อนบันทึก และหลังบ้านรับเฉพาะไฟล์ที่เสร็จแล้ว · รูปถูกย่อให้ด้านยาวไม่เกิน 1,600 px · ใบเสร็จที่เป็น PDF อยู่แล้วจะถูกต่อท้ายทั้งหน้า
- ลายเซ็นที่วาดในแอปเก็บในเครื่องนั้น (localStorage) ไม่ส่งขึ้นเซิร์ฟเวอร์นอกจากอยู่ในหน้าใบปะหน้า
- การล็อกอิน: แอปรับ ID token จาก Google Identity Services แล้วส่งไปกับทุกคำขอ หลังบ้านตรวจกับ `oauth2.googleapis.com/tokeninfo` (ตรง Client ID + อีเมลอยู่ในรายชื่อ) และแคชผลไว้ไม่เกิน 30 นาที · token อายุ 1 ชั่วโมง แอปต่ออายุเงียบ ๆ ผ่าน One Tap ถ้าไม่สำเร็จจึงกลับหน้าล็อกอิน
- Web app เปิด Anyone → มีล็อกอิน Google กั้นแล้ว จะตั้ง `APP_TOKEN` เพิ่มอีกชั้นก็ได้ · คีย์ OpenAI อยู่ใน Script Properties เท่านั้น
- ปัญหาที่พบบ่อย: "เซิร์ฟเวอร์ตอบกลับไม่ใช่ JSON" = Deploy ไม่ได้เลือก Anyone หรือใช้ URL `/dev` · แก้โค้ดแล้วไม่เปลี่ยน = ต้อง New version · ลายเซ็นไม่ขึ้น = ตรวจชื่อไฟล์ใน staff.csv ตรงกับไฟล์ในโฟลเดอร์ signatures/
